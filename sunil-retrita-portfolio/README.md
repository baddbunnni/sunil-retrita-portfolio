# Sunil Mangtani Retrita — Personal Portfolio

Dark-tech personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS v4 and Lucide icons. Includes a responsive homepage, project index and individual project pages.

## Browser-based workflow

The project can be edited in GitHub's browser editor and deployed through the connected Vercel project. Commits to the configured deployment branch trigger a new deployment.

## Before publishing

- Replace the portrait placeholder when a suitable professional photo is ready.
- Confirm the exact CIMA qualification title and the finance internship responsibilities before publishing those details as final.
- Confirm company permissions before sharing any screenshots, internal details or company-specific material about the proof-of-delivery project.
- Review project descriptions for accuracy and remove any details you prefer to keep private.
- The CV button opens a prefilled email request; it does not publish a CV file.

## Project overview

- **Proof of Delivery — iOS App:** a SwiftUI rebuild and UX refresh of an existing operational app. Existing APIs and portal are credited as existing systems.
- **Toke — Taxi Booking Platform:** a product concept in development, not represented as a launched production app.
- **FutureBite Hackathon:** a career discovery prototype focused on food engineering and manufacturing careers.
